# 项目演示视频说明

## 📹 演示内容

本目录用于存放 TeachMate V1.0 项目的功能演示视频。

### 建议录制内容

#### 1. 整体介绍视频（3-5分钟）
- 项目背景和价值
- 核心功能概览
- 使用场景介绍

#### 2. 功能演示视频

**2.1 智能教案生成演示（2-3分钟）**
- 打开教案生成页面
- 填写学科、年级、主题等信息
- 点击生成，展示 AI 思考过程
- 查看生成的教案内容
- 演示导出 Word 功能

**2.2 课堂音频分析演示（3-4分钟）**
- 打开课堂分析页面
- 上传音频文件
- 填写基本信息
- 展示分析进度
- 查看详细分析报告
- 演示改进建议和话术示例
- 演示导出 PDF 功能

**2.3 数据概览演示（1-2分钟）**
- 展示首页数据统计
- 查看趋势图表
- 浏览历史记录

### 视频要求

- **格式**：MP4
- **分辨率**：1920x1080 或更高
- **时长**：单个功能演示 2-5 分钟
- **语言**：中文
- **字幕**：建议添加中文字幕

### 文件命名规范

```
TeachMate-功能演示-教案生成.mp4
TeachMate-功能演示-课堂分析.mp4
TeachMate-功能演示-数据概览.mp4
TeachMate-项目介绍.mp4
```

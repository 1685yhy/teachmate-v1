# TeachMate V1.0 项目包结构说明

## 📦 项目包目录结构

```
TeachMate-V1.0-项目包/
├── 项目介绍.md                    # 项目介绍文件（必须）
├── 代码文件/                      # 目录1：代码文件（必须）
│   └── teachmate/                # 项目代码目录
│       ├── src/                  # 源代码
│       ├── package.json          # 项目配置
│       ├── README.md             # 详细说明文档
│       └── ...                   # 其他代码文件
├── 项目演示/                      # 目录2：项目演示（必须）
│   ├── README.md                 # 演示说明
│   └── [演示视频文件]            # 请放置演示视频
├── 设计稿/                        # 目录3：设计稿（可选）
│   ├── README.md                 # 设计说明
│   └── [设计文件]                # 请放置设计文件
├── 商业计划书/                    # 目录4：商业计划书（可选）
│   ├── README.md                 # 计划书说明
│   └── [商业计划书文件]          # 请放置商业计划书
└── 其他/                          # 目录5：其他文件（可选）
    ├── README.md                 # 其他文件说明
    └── [其他文件]                 # 请放置其他相关文件
```

## 📋 目录说明

### 根目录
- **项目介绍.md**：项目概述、核心功能、技术架构等介绍

### 目录1：代码文件（必须）
- **teachmate/**：完整的项目源代码
- **README.md**：详细的代码说明文档，包含安装、运行、API 文档等

### 目录2：项目演示（必须）
- 用于存放项目功能演示视频
- 建议包含：整体介绍、教案生成演示、课堂分析演示等

### 目录3：设计稿（可选）
- 用于存放原型设计、UI 设计等设计文件

### 目录4：商业计划书（可选）
- 用于存放项目的商业计划书

### 目录5：其他（可选）
- 用于存放项目的其他相关文件

## 📝 使用说明

1. **查看项目介绍**：阅读根目录下的 `项目介绍.md`
2. **运行代码**：进入 `代码文件/teachmate/` 目录，按照 README.md 说明运行
3. **观看演示**：查看 `项目演示/` 目录下的视频文件
4. **了解设计**：查看 `设计稿/` 目录下的设计文件（如有）

# 设计稿说明

## 📐 设计文件

本目录用于存放 TeachMate V1.0 项目的设计相关文件。

### 建议包含内容

#### 1. 原型设计
- **工具**：Figma / Axure / 墨刀
- **内容**：
  - 页面流程图
  - 交互原型
  - 功能说明

#### 2. UI 设计
- **工具**：Figma / Sketch / Adobe XD
- **内容**：
  - 设计规范（颜色、字体、间距）
  - 组件库
  - 页面设计稿
  - 图标资源

#### 3. 设计文档
- 设计思路说明
- 用户体验分析
- 交互设计说明

### 文件格式

- **设计稿**：Figma / Sketch / PDF
- **图片**：PNG / JPG（高分辨率）
- **文档**：PDF / Markdown

---

**注意**：请将实际的设计文件放置在此目录下。

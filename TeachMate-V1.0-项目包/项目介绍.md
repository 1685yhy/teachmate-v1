# TeachMate - AI教师专业发展教练 V1.0

## 📋 项目概述

**TeachMate** 是一款专为 K-12 阶段教师设计的 AI 专业发展教练工具。通过深度 AI 分析帮助教师发现教学行为盲区，提供基础改进建议，助力教师快速成长。

### 🎯 核心价值

**一句话价值描述**：让教师在 10 分钟内获得一份客观的课堂行为分析报告，明确 1-2 个关键改进点。

### ✨ 核心功能

#### 1. 智能教案生成
- **AI 模型**：DeepSeek-R1 (推理模型)
- **功能**：根据学科、年级、主题自动生成完整教案
- **特色**：思考型 AI，生成的教学设计具有深度逻辑和启发性
- **导出**：支持导出为 Word (.docx) 格式

#### 2. 课堂音频分析
- **AI 模型**：DeepSeek-V3 (对话模型)
- **分析指标**：
  - 开放式问题比例
  - 教师语速（字/分钟）
  - 积极反馈次数
- **输出**：详细的分析报告 + 具体改进建议 + 话术示例

#### 3. 数据可视化
- 本周数据概览（课时数、教案数、核心指标）
- 开放式问题比例趋势图（最近 5 次）
- 历史记录快速查看

### 🛠 技术架构

- **前端框架**：Next.js 14 (App Router)
- **UI 框架**：Tailwind CSS
- **AI 服务**：DeepSeek (R1 & V3)
- **数据存储**：浏览器本地持久化 (LocalStorage)
- **图标库**：Lucide React
- **文档生成**：docx, file-saver

### 📊 项目数据

- **版本**：V1.0 MVP（基础能力版）
- **目标用户**：K-12 阶段新教师、骨干教师
- **项目周期**：6 周
- **目标用户数**：50 位种子教师

### 🚀 快速开始

#### 本地运行
```bash
npm install
npm run dev
```
访问：http://localhost:3000

#### 部署到 Vercel
1. 将代码推送到 GitHub
2. 在 Vercel 导入项目
3. 配置环境变量：
   - `OPENAI_API_KEY`: DeepSeek API Key
   - `OPENAI_BASE_URL`: https://api.deepseek.com
4. 一键部署完成

### 💡 使用场景

#### 场景 1：课后快速复盘
教师上完课后，上传课堂录音，5 分钟内获得专业分析报告，发现"封闭式问题过多"等问题，并获得具体改进话术。

#### 场景 2：课前快速备课
教师需要准备新课，输入主题和基本信息，30 秒内获得一份完整的教案，可直接使用或微调。
